Учебный проект: исследовательский анализ данных сервиса "Яндекс Афиша"

Содержимое:
- nklvk_project.ipynb - код проекта в тетради Jupiter Notebook
- requirements.txt - список библиотек необходимых для корректной работы проекта
- .env.example - пример файла с переменными из оригинального .env (без значений)
- README.md - краткое описание проекта
- .gitignore - файлы, не требующие коммитов

Краткое описание проекта:
Проект: Исследование факторов удержания пользователей сервиса «Яндекс Афиша»

Цель проекта: помочь маркетинговой команде «Яндекс Афиши» увеличить долю повторных покупок. Основная задача — выявить характеристики пользователей и параметры их первого заказа, которые способствуют возвращению клиента на платформу.

Задачи проекта:
- Сбор данных: Подключение к базе данных SQL и выгрузка информации о транзакциях, событиях и пользователях.
- Предобработка: Очистка данных от аномалий, обработка пропусков и приведение данных к нужным типам (включая конвертацию валют).
- Профилирование: Создание портрета пользователя на основе его первой покупки и последующей активности.
- Анализ: Изучение распределений и поиск закономерностей в поведении лояльных клиентов.
- Корреляционный анализ: Использование коэффициента phik для оценки влияния различных факторов (категория события, тип устройства, регион) на количество совершенных заказов.
- Рекомендации: Формирование стратегии для маркетинга по удержанию перспективных сегментов аудитории.

Результат проекта: изучены факторы, влияющие на возврат пользователей, даны рекомендации для дальнейшей работы команды маркетинга
